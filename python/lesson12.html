Приклад коду для повторення (поясни вголос кожен рядок і що виведе програма): 

import random

NUMBERS = [10, 20, 30, 40, 50, 60]
print(len(NUMBERS))

copied = NUMBERS.copy()

part = copied[2:4]
print(part)

random.shuffle(copied)
print(copied)

print(NUMBERS)

Чому NUMBERS написано ВЕЛИКИМИ ЛІТЕРАМИ? Це не правило Python, а домовленість між програмістами: змінні у ВЕРХНЬОМУ РЕГІСТРІ позначають дані, які не повинні змінюватися під час роботи програми.

Нова тема

Список словників

Ти вже знаєш, як зберегти інформацію про один обʼєкт в одному словнику. — наприклад, один фрукт: 

fruit1 = {"name": "banana", "color": "yellow"}

Якщо ж фруктів є багато, можна зібрати усі словники в один список: 

# ПРИКЛАД 1

fruit1 = {"name": "banana", "color": "yellow"}
fruit2 = {"name": "grape", "color": "purple"}
fruit3 = {"name": "apple", "color": "green"}

fruits = [fruit1, fruit2, fruit3]

print(fruits[0])
print(fruits[0].get("name"))
print(fruits[0].get("color"))

Щоб звернутися до конкретного фрукта, потрібно виконати два кроки:

  1. За допомогою індексу отримати зі списку потрібний словник (наприклад, fruits[0])
  2. Використати ключ, щоб отримати зі словника потрібну інформацію (fruits[0].get("name"))

Уяви це як полицю з коробками: fruits – це полиця, fruits[0] – перша коробка на ній, а .get("name") — конкретна річ у коробці.

Перебір у циклі

Найчастіше зі списком словників працюють через цикл for, щоб не звертатися до кожного елемента вручну: 

# ПРИКЛАД 2

fruit1 = {"name": "banana", "color": "yellow"}
fruit2 = {"name": "grape", "color": "purple"}
fruit3 = {"name": "apple", "color": "green"}

fruits = [fruit1, fruit2, fruit3]

for fruit in fruits:
    name = fruit.get("name")
    color = fruit.get("color")
    print(f"{name} is {color}")

На кожному кроці циклу fruit — це один словник зі списку (спочатку fruit1, потім fruit2, потім fruit3).

Коротший запис

Список словників не обов'язково збирати з окремих змінних — можна одразу записати його як єдиний список: 

# ПРИКЛАД 3

fruits = [
    {"name": "banana", "color": "yellow"},
    {"name": "grape", "color": "purple"},
    {"name": "apple", "color": "green"},
]

for fruit in fruits:
    name, color = fruit.get("name"), fruit.get("color")
    print(f"{name} is {color}")

Тут name, color = fruit.get("name"), fruit.get("color") — це спосіб дістати одразу два значення в одному рядку. Це те саме, що написати два окремі рядки, просто коротше.

Патерн для підрахунку балів

questions = [
    {"question": "6 * 7", "answer": 42},
    {"question": "132 / 3", "answer": 44},
]

score = 0 # 1. create

for q in questions:
    question, correct = q.get("question"), q.get("answer")
    
    user_answer = int(input(question + " = "))
    
    if user_answer == correct:
        score += 1 # 2. update

print(f"\nYour result: {score}/{len(questions)}") # 3. print the final result

Крок 2

Крок 5

Додай можливість обирати напрямок перекладу: з англійської на українську або навпаки:
