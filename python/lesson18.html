Tkinter 2: Entry, Frame та Text

Поле введення Entry

Що таке Entry

На минулому уроці ми розглянули, як показувати текст (Label) і реагувати на кліки (Button). Сьогодні ознайомимося із новим віджетом, який дозволяє запитувати дані у користувача – Entry. Це поле для введення одного рядка тексту: 

from tkinter import *

window = Tk()
window.geometry("400x250")
window.eval("tk::PlaceWindow . center")

entry = Entry(
    window,
    font=("Arial", 14),
    width=20,
)
entry.pack(pady=20)

window.mainloop()

Пояснення параметрів:

  • window – у якому контейнері розмістити поле.
  • font – шрифт тексту, який вводить користувач.
  • width=20 – ширина поля. Увага: вона вимірюється в символах, а не в пікселях. width=20 означає, що вміститься приблизно 20 літер.
  • Також працюють bg (колір фону поля) та fg (колір тексту).

Також можна змінити вигляд контуру поля:

entry = Entry(
    window,
    font=("Arial", 14),
    width=20,

    bd=0,                             # прибирає стандартну об'ємну рамку
    highlightthickness=3,             # товщина нової рамки (в пікселях)
    highlightbackground="lightblue",  # колір рамки у звичайному стані
    highlightcolor="blue",            # колір рамки, коли поле активне (в ньому курсор)
)

Як отримати введені дані: .get()

Отже, користувач ввів у поле якийсь текст. Як отримати цей текст із поля, щоб використати його далі в програмі? Для цього існує метод .get(). Він повертає вміст поля: 

user_input = entry.get()

Але цей метод потрібно використовувати всередині функції, яка викликається при натисканні кнопки. Якщо помістити його поза функцією, він викличеться лише один раз одразу при запуску програми, коли користувач ще не встиг нічого ввести, і поверне порожній рядок "".

Розглянемо простий приклад:

from tkinter import *

window = Tk()
window.geometry("400x250")

entry = Entry(window, font=("Arial", 14), width=20)
entry.pack(pady=10)

def show_text():
    user_input = entry.get()
    label.config(text=user_input)

btn = Button(window, text="Print", command=show_text, font=("Arial", 12))
btn.pack(pady=10)

label = Label(window, text="", font=("Arial", 16))
label.pack(pady=10)

window.mainloop()

Щоб після виведення тексту на екран очистити текстове поле, можна використати метод .delete(): 

def show_text():
    user_input = entry.get()
    label.config(text=user_input)
    entry.delete(0, END) # видаляє весь текст

Також варто зважати, що .get(), як і input(), повертає текстовий рядок, і на число його треба перетворювати з int() або float().

Розташування віджетів – Frame

Що таке Frame

Метод .pack() за замовчуванням розташовує віджети один під одним, і це не завжди зручно. Що як потрібно розмістити дві кнопки поруч? Або підпис і поле введення в один рядок. Для цього є віджет Frame.

Frame – це рамка, яка знаходиться у вікні, а всередині неї можна помістити інші віджети. Це ніби "вікно всередині вікна".

Спочатку створюємо Frame і розміщуємо його у вікні. Потім створюємо віджети, але в якості контейнера вказуємо вже не window, а цей Frame: 

buttons_frame = Frame(window)
buttons_frame.pack(pady=10)

btn1 = Button(
    buttons_frame,
    text="Left",
    font=("Arial", 14),
)
btn1.pack(side=LEFT, padx=5)

btn2 = Button(
    buttons_frame,
    text="Right",
    font=("Arial", 14),
)
btn2.pack(side=LEFT, padx=5)

Щоб віджети всередині рамки стали в рядок, всередині .pack() використовуємо параметр side. Він може приймати такі значення:

Значення Де розміщується віджет
TOP зверху (за замовчуванням – віджети стають один під одним)
LEFT зліва (віджети стають у рядок зліва направо)
RIGHT справа (віджети стають у рядок справа наліво)
BOTTOM знизу (віджети стають знизу вгору)

Багаторядкове поле Text

Що таке Text

Entry вміщує лише один рядок. Якщо потрібно ввести більший текст (нотатку, повідомлення чи історію на кілька рядків), використовують віджет Text: 

from tkinter import *

window = Tk()
window.geometry("450x350")
window.config(bg="lavender")
window.eval("tk::PlaceWindow . center")

notes = Text(
    window,
    font=("Arial", 14),
    width=30,
    height=8,
    wrap=WORD,
)
notes.pack(pady=20)

window.mainloop()

Пояснення параметрів:

  • width=30 – ширина в символах (як і в Entry).
  • height=8 – висота в рядках (не в пікселях!).

Читання та зміна тексту

Оскільки в Text багато рядків, початок тексту позначається як "1.0" (1-й рядок, 0-й символ), а кінець – END (або "end-1c" при читанні, щоб не захопити зайвий перенос рядка \n у кінці):

Команда Що робить
notes.get("1.0", "end-1c") повертає весь введений текст
notes.delete("1.0", END) видаляє весь текст
notes.insert("1.0", "...") вставляє текст на початок поля

Щоб змінити текст у полі, виконуємо три кроки: читаємо старий текст (get), очищуємо поле (delete) і вставляємо новий (insert): 

def add_stars():
    content = notes.get("1.0", "end-1c")   # 1. прочитали
    notes.delete("1.0", END)               # 2. видалили старий
    notes.insert("1.0", f"✨ {content} ✨") # 3. вставили змінений

А щоб порахувати кількість слів у тексті, достатньо розбити прочитаний рядок за пробілами методом .split() і знайти довжину списку: 

def count_words():
    content = notes.get("1.0", "end-1c")
    words = len(content.split())
    label.config(text=f"Words: {words}")

Вгадай число

Створи мінігру з графічним інтерфейсом: комп'ютер загадує випадкове число від 1 до 10, а гравець намагається його вгадати через поле Entry.

Вікно має містити зверху вниз:

  1. напис з інструкцією "Guess a number from 1 to 10:"
  2. поле для введення числа
  3. кнопку "Check"
  4. порожній напис для підказки (на початку гри він нічого не показує)

Після натискання на "Check" напис для підказки показує одне з трьох повідомлень:

  • "Too low!" – введене число менше за загадане;
  • "Too high!" – введене число більше за загадане;
  • "You guessed it! 🎉" – число вгадано.

Число потрібно загадати один раз, до початку гри (поза функцією). Інакше воно буде змінюватися при кожному натисканні, і вгадати його буде неможливо. Нагадування, як це зробити: 

import random
secret_number = random.randint(1, 10)

Введене число зчитуй через int(entry.get()). Якщо ввести не число, виникне помилка – поки що ігноруй цей випадок.

Ось як має виглядати результат:

Підказка

У функції для кнопки "Check" спочатку зчитай число з поля, а потім порівняй його із загаданим через if / elif / else. У кожній гілці змінюй текст напису для підказки через label.config(text=...).

Бонус ⭐ (необов'язково)
  1. Якщо ввести не число, напис має показувати "Please enter a number!" (використай try / except з уроку 15).
  2. Після кожної перевірки поле для введення очищується (entry.delete(0, END)).
  3. Додай кнопку "New game", яка загадує нове число та очищує напис для підказки. Тут знадобиться global.
