Повторення та структура програми

Як працює main() та "меню нижчого рівня"

Уяви функцію main() як головний пульт управління програмою або директора фабрики. Вона сама не виконує "брудної роботи" (не перемішує списки і не рахує бали), а лише по черзі роздає команди іншим функціям. Це робить код дуже читабельним: глянувши на main(), ми одразу розуміємо загальний сценарій.

Але інколи програма настільки велика, що "директору" потрібні "менеджери". У програмуванні можна створювати функції, які теж керують іншими, дрібнішими функціями.

У нашому проєкті таким менеджером буде функція run_quiz(). Її завдання — запустити власне саму вікторину. Вона буде циклом проходити по словах і викликати собі на допомогу функції-помічники для створення та перевірки питань та відповідей.

Сьогодні ми будуємо таку структуру:

main()
 ├── get_practice_words()
 ├── limit_words()
 ├── choose_mode()
 ├── run_quiz()
 │      ├── make_question()   ← викликається для кожного слова
 │      └── ask_question()    ← викликається для кожного слова
 └── show_result()

make_question(), ask_question() та тестування

Як повернути кілька значень одразу

У Python функції можуть повертати не лише одне значення, а одразу кілька. Для цього їх достатньо просто перерахувати через кому після return. А щоб "зловити" ці результати, ми ставимо таку саму кількість змінних через кому під час виклику функції. Наприклад: 

import random

def get_two_numbers():
    num1 = random.randint(1, 6)
    num2 = random.randint(1, 6)
    return num1, num2 # 🌻 повертаємо два значення

a, b = get_two_numbers() # 🌻 "ловимо" два значення у дві змінні

Тестування

Навіщо тестувати кожну функцію окремо?

При написанні коду часто виникають помилки. Навіть професійні програмісти не пишуть ідеальний робочий код із першої спроби. І чим більше коду, тим більше накопичується помилок, і тим складніше їх стає шукати та виправляти. Тому корисною звичкою є тестування окремих функцій перед тим, як підключати їх у основний проєкт. Для тестування часто вводяться тимчасові тестові дані.

Повторення: early return (раннє повернення)

Замість того, щоб створювати додаткову змінну, записувати в неї результат через if/else і повертати її в самому кінці функції, ми можемо використати підхід early return (раннє повернення).

Коли Python зустрічає команду return, він одразу зупиняє виконання функції і виходить із неї. Тому нам більше не потрібен блок else: якщо умова в if виконається, функція завершить роботу достроково. Якщо ж ні — код просто піде далі.

Звичайний спосіб (з else):

def check_password(pwd):
    if pwd == "1234":
        print("correct")
        return True
    else:
        print("wrong")
        return False

Early return (без else):

def check_password(pwd):
    if pwd == "1234":
        print("correct")
        return True  
    
    print("wrong")
    return False

Менеджер другого рівня: run_quiz()

Настав час створити нашого "менеджера другого рівня" – функцію run_quiz. Ця функція пройдеться по черзі по кожному слову зі списку за допомогою циклу for і для кожного слова сформує питання, задасть його користувачу, перевірить його відповідь, і, нарешті, порахує і поверне нам загальну кількість правильних відповідей за все тренування. По суті, це основна логіка нашої програми.
