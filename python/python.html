Цикли: for, while

Мета цього уроку:

  • Зрозуміти різницю між циклами for та while.
  • Навчитися керувати нескінченними циклами за допомогою break і continue.
  • Написати безпечні запити вводу користувача.
  • Застосувати цикли для розв'язання логічних задач.

Частина 1. Цикли for з range()

▶

for i in range(n)

Цикл із відомою кількістю повторів. Використовуємо, коли наперед відомо, скільки саме разів треба повторити дію. 

for i in range(5):
    print(i)

range(n) — це числа від 0 до n-1.

  • Скільки разів виконається print(i) в циклі for i in range(255)?
  • Яке число надрукується першим, а яке — останнім?

for i in range(n, m)

Цикл у діапазоні від n до m (не включно з m). 

for i in range(3, 8):
    print(i)

Починаємо не з нуля, а з n, і зупиняємось на m - 1.

  • Як треба змінити цикл з прикладу, щоб вивести всі числа від 15 до 25 включно?

Вкладені цикли

Зовнішній цикл — «рядки», внутрішній — «стовпці». Для кожного значення i внутрішній цикл проходить повністю по всіх значеннях j, перед тим, як перейти до наступного i. 

for i in range(2):
    for j in range(3):
        print(f"i = {i}, j = {j}")
    print("------------")
for i in range(1, 4):
    for j in range(7, 9):
        print(f"i = {i}, j = {j}")
    print("------------")
  • В першому прикладі — скільки разів виконається print(f"i = {i}, j = {j}"), а скільки разів print("------------")?
  • А в другому прикладі — які значення послідовно набуває j?

Частина 2. Цикл while

▶

while — поки виконується умова

Синтаксис: while умова: — тіло циклу виконується знову і знову, поки умова істинна. Щойно умова стає хибною — цикл зупиняється сам. 

count = 1          # змінна-лічильник
while count <= 3:  # умова зупинки
    print(count)
    count += 1     # змінюємо значення
  • Яким буде результат цього коду?
count = 0          
while count <= 10: 
    count += 2
    print(count)

⚠️ Нескінченний цикл. Якщо умова в while ніколи не стає хибною, цикл виконуватиметься вічно, і програма «зависне».

Правило: всередині циклу обов'язково має бути дія, яка рано чи пізно зробить умову хибною. Якщо програма зависла в Thonny — зупинити її можна червоною кнопкою Stop. Якщо такий цикл виник в редакторі коду на цьому сайті – онови сторінку. 

num = 5
while num > 0:
    print(num)
    num += 1

# num постійно зростає, тому умова num > 0 ніколи не стане хибною
  • Що можна змінити в коді вище, щоб цикл завершився?

Відмінність від for

Головна відмінність: не обов'язково знати наперед, скільки буде повторів, — це визначає умова, а не лічильник чи довжина списку.

Наприклад, енергія персонажа зменшується випадковим чином:

import random

energy = 100

while energy > 0:
    energy -= random.randint(5, 25)
    if energy < 0:
        energy = 0
    print(f"Energy left: {energy}")

print("\nGame over!")

Ще один приклад — просимо ввести пароль, доки користувач не введе правильний (може вгадати з першої спроби, а може й зі сотої): 

password = "1111"

answer = None
while answer != password:
    answer = input("Enter the password: ")

print("That's correct. Access granted.")
  • Як думаєш, навіщо перед циклом написано answer = None?

Частина 3. break, continue та while True

▶

break і continue

  • continue — пропускає решту тіла циклу й переходить до наступної ітерації (починає коло знову).
  • break — негайно розриває цикл і повністю виходить із нього. 
for num in range(100):
    if num == 3:
        continue
    if num == 7:
        break
    print(num, end=" ")
  • Чому серед надрукованих чисел немає числа 7?
  • Як змінити першу умову, щоб пропустити не лише число 3, а всі числа, які діляться на 3 без остачі?

Особливий патерн: while True

Іноді умову виходу з циклу можна перевірити лише після якоїсь дії всередині циклу — наприклад, спочатку треба запитати ввід користувача, і тільки тоді перевірити, чи він коректний.

Спосіб 1 — визначаємо змінну перед циклом:

total = 0
number = None

while number != 0: # умова зупинки тут
    number = int(input("Enter a number (0 = stop): "))
    total += number

print(f"Sum = {total}")

Спосіб 2 — задаємо умову зупинки всередині через while True та break: 

total = 0

while True:
    number = int(input("Enter a number (0 = stop): "))
    
    if number == 0: # умова зупинки тут
        break
        
    total += number

print(f"Sum = {total}")

Це не окремий вид циклу, а прийом поверх звичайного while: цикл формально «нескінченний», а умову завершення визначає break.

Ще один приклад — запитуємо текст, очищаємо його і виводимо. Якщо не введено нічого — пропускаємо ітерацію (continue), якщо введено "q" — завершуємо програму: 

while True:
    answer = input("Enter some text or 'q' to stop: ").strip().lower()

    if answer == "":
        continue

    if answer == "q":
        break

    print(f"Your input: {answer}")

print("Goodbye!")

Приклад 1: Перевірка коректності вводу

Просимо число від 1 до 5, поки не введуть правильно (обробляємо і «не число», і «число поза діапазоном»): 

while True:
    user_input = input("Enter a number from 1 to 5: ")

    if not user_input.isdigit():
        print("It's not a number. Try again!")
        continue

    number = int(user_input)

    if number < 1 or number > 5:
        print("The number must be from 1 to 5. Try again!")
        continue

    break

print("Thanks. Accepted number:", number)

Метод .isdigit() повертає True, якщо рядок складається лише з цифр 0–9 (без пробілів, крапок, мінуса тощо), і False в усіх інших випадках.

Нюанс: від'ємні числа він не розпізнає, бо знак мінуса — не цифра. Якщо потрібні й від'ємні відповіді, рядок спершу очищають: answer.lstrip("-").isdigit().

  • Чому перевірка user_input.isdigit() стоїть саме перед int(user_input), а не після?
  • Що виведе програма, якщо ввести "-3"?

Приклад 3: Цикл всередині функції

Функція «ховає» всередині себе нескінченний цикл, а назовні віддає вже перевірене значення через return — писати окремий break не потрібно, адже return миттєво завершує і цикл, і саму функцію: 

def ask_number():
    while True:
        answer = input("Enter an integer: ")

        if not answer.lstrip("-").isdigit():
            print("That's not an integer!")
            continue

        return int(answer)

n1 = ask_number()
n2 = ask_number()
print(n1, n2)

Завдання: Каталог фільмів

Напиши програму, яка працює точно як на відео нижче. Це повноцінне інтерактивне меню для керування списком фільмів.

Скріншоти

Кроки для реалізації:

  • Якщо користувач ввів "v" — виведи по черзі кожен фільм із нумерацією у форматі "1. Назва фільму".
  • Якщо "a" — запитай назву нового фільму та додай його до списку movies.
  • Якщо "r" — запитай назву фільму. Якщо він є у списку — видали його, якщо немає — виведи "This movie isn't in the list.".
  • Якщо "p" — за допомогою random.choice() обери та виведи випадковий фільм на вечір.
  • Якщо "q" — виведи прощання і зупини цикл за допомогою break.
  • Якщо введено будь-яку іншу команду — виведи "Unknown command."
