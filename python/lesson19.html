Багаторядкове поле Text

Створення поля Text

Віджет Entry підходить лише для одного короткого рядка (ім'я, пароль, число). Якщо ж нам потрібно поле для нотаток, повідомлень або великого тексту з кількома рядками, використовують віджет Text: 

notes = Text(window, width=40, height=8, font=("Arial", 12), wrap=WORD)
notes.pack(padx=10, pady=10)

Основні параметри:

  • width=40 – ширина поля у символах (літерах), а не пікселях.
  • height=8 – висота поля у рядках.
  • wrap=WORD – переносить слова на новий рядок цілими (без цього параметра довге слово розірветься просто посередині).
  • Параметри font, bg та fg працюють так само, як у Label та Entry.

Позиції у Text

Оскільки в полі Text багато рядків, позиція кожного символу записується як рядок у форматі "рядок.символ":

  • Номери рядків починаються з 1.
  • Номери символів у рядку починаються з 0.
Позиція Що означає
"1.0" Рядок 1, символ 0 — самий початок тексту (завжди в лапках!)
END Самий кінець тексту
"end-1c" Кінець тексту мінус останній невидимий перенос рядка (використовуємо під час читання)

Читання та очищення: .get() і .delete()

На відміну від Entry, у віджеті Text метод .get() обов'язково приймає два аргументи: звідки і доки читати текст. 

# Прочитати весь текст із поля
content = notes.get("1.0", "end-1c")

# Очистити все поле
notes.delete("1.0", END)

Вставка та «рецепт» зміни тексту

Метод .insert(позиція, текст) додає текст у вказане місце: 

notes.insert(END, "Hello!\n")    # додати в кінець
notes.insert("1.0", "Title\n")   # додати на самий початок

Щоб змінити текст, який вже написаний у полі, ми завжди виконуємо три кроки (прочитати → видалити старий → вставити новий): 

def to_upper():
    content = notes.get("1.0", "end-1c")   # 1. Прочитати текст
    notes.delete("1.0", END)               # 2. Видалити старий текст
    notes.insert("1.0", content.upper())   # 3. Вставити змінений текст
💡 Подумай: що станеться, якщо у функції вище пропустити крок 2 (notes.delete("1.0", END))?

Практика: Text Toolbox 🧰

Мініпроєкт: Text Toolbox

Створимо власний текстовий редактор із панеллю інструментів! Рекомендуємо додавати кнопки по одній і одразу перевіряти, як вони працюють.

Рівень 1: Основні кнопки
  1. Створи вікно та додай у нього багаторядкове поле Text (із параметром wrap=WORD).
  2. Під полем створи рамку Frame для кнопок.
  3. Додай у рамку три кнопки в один рядок (side=LEFT):
    • "UPPER" — переводить увесь текст у ВЕЛИКІ літери (.upper());
    • "lower" — переводить увесь текст у маленькі літери (.lower());
    • "Clear" — повністю очищує поле.

Рівень 2: Підрахунок слів (Count)
  1. Додай під рамкою з кнопками напис Label із початковим текстом "Words: 0".
  2. Додай у рамку ще одну кнопку — "Count", яка рахує кількість слів у полі Text і оновлює напис.

💡 Підказка: щоб порахувати слова в рядку content, розбий його за пробілами через .split() і знайди довжину списку: 

words_count = len(content.split())

Рівень 3 (Бонус): Capital

Додай кнопку "Capital", яка робить першу літеру тексту великою, а всі інші — маленькими за допомогою методу .capitalize().
